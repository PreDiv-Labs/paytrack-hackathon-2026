# PayTrack research and integration decisions

Reviewed November 11, 2026. The official deadline is November 12, 2026 at 12:00 PST (November 13 at 01:30 IST).

## Competition

Sources: [overview and judging](https://paypalaihackathon.devpost.com/), [rules](https://paypalaihackathon.devpost.com/rules), [resources](https://paypalaihackathon.devpost.com/resources).

Projects must meaningfully combine PayPal and AI. The five judging criteria cover implementation, design, impact, innovation, and presentation. A functional demo is required; complete repository setup instructions may substitute for hosting. Submission also needs a public open-source repository and a public YouTube demonstration under three minutes. A static product preview alone does not qualify.

PayTrack prioritizes Overall and Best Use of PayPal + AI. No award eligibility or outcome is guaranteed. The AG Grid award asks for Studio custom widgets, theming/layout, and agent framework depth; a Community grid and standalone charts do not demonstrate that full scope.

## PayPal and AI choices

- [PayPal developer platform](https://developer.paypal.com/) and authoritative [Orders v2 schema](https://developer.paypal.com/api/orders/v2/schema.json): create, approve, capture, then independently retrieve and verify an order.
- [Login with PayPal](https://developer.paypal.com/log-in/build), [scope reference](https://developer.paypal.com/log-in/references.md) and [Identity schema](https://developer.paypal.com/api/identity/v1/schema.json): OAuth subject identifies an account; only explicitly supplied `payer_id` links Checkout financial attribution. Email is never used to link ledger entries.
- [Webhooks API](https://developer.paypal.com/api/webhooks/v1): verify signature with PayPal before processing; retrieve authoritative financial state; duplicate events have no additional ledger effect.
- [Payments v2](https://developer.paypal.com/api/payments/v2): retrieve completed refunds and record opposite-direction cash flows. Refund initiation remains in the merchant's PayPal dashboard.
- [PayPal AI Toolkit](https://github.com/paypal/AI-Toolkit) is currently a development plugin with PayPal API skills and Sandbox MCP access. It is not a hosted financial language model. MCP requires additional agent authentication; unrestricted runtime payment tools are not needed here. It was researched but not installed or claimed as a runtime integration. The legacy `docs.paypal.ai` URL redirected to an unavailable docs path during research; current developer documentation and the official repository were used instead.
- [Gemini structured outputs](https://aistudio.google.com/docs/structured-output): optional model selects from precomputed fact IDs, category recommendation IDs, and four allowed chart views. Zod validates all selections. No raw transaction descriptions, identity emails, OAuth tokens, SQL or payment tools enter the model context. All displayed numbers are rendered deterministically. A provider key and successful real model test are still required before claiming an operational AI demo.

## Stack compatibility

Next.js 16.4.6 App Router, React 19.3.1, strict TypeScript, Tailwind 4, Auth.js 5 beta.32 (pinned), Prisma 6.19.3, PostgreSQL/Neon, Radix accessible dialogs, locally owned shadcn-style button primitive, Lucide, AG Grid 36.3.0 and AG Charts 14.3.0. Prisma 6 keeps datasource URL in the schema; Prisma 7/8 configuration is deliberately not mixed into this app. Dependencies are resolved in the lockfile. Transitive security overrides are validated by lint, Prisma CLI, tests and production build.
